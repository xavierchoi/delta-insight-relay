# 세션 로그 전송

Delta Society가 진행하는 Claude Code 교육 회차 종료 시, 참가자의 세션 트랜스크립트를 Delta 서버로 전송하는 스킬. 전송된 로그는 다음 회차 개선을 위한 분석에만 쓰인다.

## 왜 인터뷰 방식인가

참가자는 인증코드 외에는 아무것도 사전에 설정하지 않는다. 필요한 정보는 대화로 직접 물어봐서 채운다 — 설정 파일이나 커맨드라인 인자를 참가자가 직접 다루게 하면 오탈자나 혼란이 생기기 쉽고, 교육 환경에서는 "그냥 대화하듯 답하면 끝"이 훨씬 매끄럽다.

## 실행 순서

1. **인터뷰** — 아래 네 가지를 참가자에게 순서대로 묻는다. 이미 대화 중에 언급된 정보가 있으면 다시 묻지 않는다.
   - 인증코드 (교육 진행자가 알려준 코드)
   - 참가자 이름
   - 회차 제목
   - 회차 번호
2. **확인** — 받은 네 가지 값을 요약해서 보여주고 맞는지 확인받는다. 오탈자가 있으면 이 단계에서 잡는다.
3. **전송** — 확인을 받으면 `scripts/upload.sh`를 실행한다:
   ```
   bash <스킬 디렉토리>/scripts/upload.sh "<인증코드>" "<참가자 이름>" "<회차 제목>" "<회차 번호>"
   ```
   날짜는 스크립트가 자동으로 채우고, 전송할 트랜스크립트 파일도 스크립트가 현재 세션 기준으로 알아서 찾는다 — 참가자나 Claude가 파일 경로를 직접 지정할 필요 없다.
4. **결과 보고** — 스크립트 종료 코드와 출력을 그대로 참가자에게 전달한다.
   - 성공: "전송 완료"로 끝나면 성공을 알린다.
   - 실패: 실패 메시지를 그대로 보여주고, 인증코드 오타 등 참가자가 고칠 수 있는 문제면 재시도를 제안한다. 서버 쪽 문제로 보이면 진행자에게 문의하라고 안내한다.

## 주의사항

- 이 스킬은 세션 자체를 분석하거나 요약하지 않는다 — 원본 트랜스크립트를 그대로 전송하는 것이 전체 목적이므로, 별도 가공 없이 파일을 통째로 보낸다.
- 같은 회차에 대해 여러 번 전송을 요청받으면, 매번 정상적으로 다시 전송한다 (덮어쓰기/중복 처리는 서버 책임).
